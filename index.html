A simple place to start

Keep Instagram, Facebook, TikTok and YouTube together as website bookmarks. Choose only the sites you want. Hold two fingers on a webpage to open browser controls, enter another website address or return to your start page.

Your accounts stay with the websites

No Socials Wider account is needed. Each website handles its own sign-in and security checks. Website availability and features can differ from the native apps. Password suggestions and biometric confirmation depend on the website and Apple’s system support.

Make it yours

Choose from the bundled backgrounds, then add the optional widget through your iPhone’s Home Screen controls. The widget opens the selected website inside Socials Wider.
